# 任天堂 iQue V2 组件清单

[English README](README.md)

本目录的五个文件是任天堂 iQue V2 已解压组件的 Ghidra 地址化导出。P1/P3 为 ARM9
执行模式，P2/P4 为 ARM7 执行模式，P5 保留为显式数据。装载地址证据详见
[技术说明](../../TECHNICAL.zh-cn.md)。

| 文件 | 运行期地址 | 原始组件长度 |
| --- | --- | --- |
| `p1.s` | `0x02320000` | `0x14584` |
| `p2.s` | `0x037FA800` | `0xB304` |
| `p3.s` | `0x02364900` | `0x17940` |
| `p4.s` | `0x02300200` | `0xD94C` |
| `p5.s` | `0x0237C240` | `0x5EAA0` |
