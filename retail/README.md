# Retail firmware reconstructions

This directory contains the ten recovered Nintendo retail firmware variants.
Run `make` to rebuild every variant, `make verify-firmware` to check every
normalised CRC32 against the records in the sibling `dscfw` repository, or
enter an individual version directory to build only that variant.

---

# 零售固件重建

本目录包含十个已恢复的任天堂零售固件变体。运行 `make` 可重建全部版本；运行
`make verify-firmware` 可依据相邻 `dscfw` 仓库的记录校验全部归一化 CRC32；也可进入
单个版本目录，仅构建该版本。
